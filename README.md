# Cross-Mouse Generalization of Distributional Reward Coding in the Striatum

This repo asks whether the striatal "distributional" code for reward — specifically, the population-level distinction between Fixed and Variable reward-predicting odours reported by Lowet et al. (2025, *Nature*) — is encoded in a shared, canonical geometric format across mice, or whether each animal implements this code idiosyncratically.

To test this, cross-subject alignment methods adapted from Chen, Manning, & van der Meer (2021, *Current Biology*) — originally developed to test shared representational geometry in the rodent hippocampus — are applied to the Lowet et al. striatal dataset. Neural trajectories from each mouse are reduced to a shared low-dimensional PCA space and then aligned across mice via Generalized Procrustes Analysis (rotation, reflection, translation only), before testing whether this shared space supports above-chance cross-mouse decoding of Fixed vs. Variable trial identity.

## Repo contents

- `distRL_cross_mouse_generalization.ipynb` — main analysis notebook. Built to run on **Google Colab**; downloads the required Lowet et al. data directly from Dryad within the notebook.
- `report.md` — full write-up (introduction, methods, results, conclusion) with figures.
- `figures/` — figures generated by the notebook and referenced in `report.md`.

## Main findings

- Procrustes-aligned cross-mouse decoding of Fixed vs. Variable trials was significantly above an unaligned (PCA-only) floor, and significantly below the within-mouse (split-half) ceiling — evidence of a partially shared representational geometry across mice.
- A classifier and alignment template fit once on a random subset of mice and deployed without further fitting to fully unseen mice still decoded Fixed vs. Variable trials well above chance (mean accuracy ≈ 0.72), showing the shared structure generalizes to animals never seen during alignment.
- A matched training-set-size control showed that, once training-set size is equalized, within-animal information is still more predictive than across-animal information — so the code is not fully canonical, but retains meaningful animal-idiosyncratic structure.

See `report.md` for full methods, statistics, and figures.
